Om projektet

C# Numerics är ett lättanvänt men kraftfullt numeriskt bibliotek som kombinerar klassisk numerisk analys med moderna C#-idiom som extension-metoder. Fokus ligger på läsbar kod, numerisk stabilitet och vetenskaplig användning.

Varför C# Numerics?

  • 📐 Extension-metoder ger extremt ren och uttrycksfull kod
  • ⚙️ Fokus på klassisk numerisk analys (ODE, FFT, linjär algebra)
  • 🧪 Designat för testbarhet och reproducerbara beräkningar
  • 🧠 Utvecklat av fysiker inte bara API:er, utan numerisk förståelse

Höjdpunkter

Numeriska metoder

Newton–Raphson, derivator, integraler, Monte Carlo.

Linjär algebra

Vektorer, matriser, egenvärden, linjära system.

Differentialekvationer

Euler, RK4, initialvärdesproblem.

Spektrala metoder

FFT, DFT, Laplace-transform, signalanalys.

Kodexempel

Fakultet

// 5! = 120
int result = 5.Factorial();

Newton–Raphson

Func f = x => x*x - 4;
double root = f.NewtonRaphson(); // 2

Runge–Kutta (RK4)

Func<(double t,double y), double> ode = v => Math.Tan(v.y) + 1;
var y1 = ode.RungeKutta(1, 1.1, 0.025, 1);
